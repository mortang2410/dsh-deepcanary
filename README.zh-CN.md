# DeepCanary

**任务安心运行，需要处理时及时提醒，回来后直接找到正确会话。**

[English](README.md) · 简体中文 · [文档](docs/README.md) · [更新记录](CHANGELOG.md)

DeepCanary 为 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) 提供本地决定收件箱，将智能体已作出的决定和等待你回答的决定集中呈现，并按通知预算和静默时段减少打扰。

**当前发布候选为 0.1.6-rc.4。** 宿主基线为已发布的 DSH **0.2.1-rc.2**，覆盖 WebUI 与官方 Windows Desktop。安装包见 [npm](https://www.npmjs.com/package/dsh-deepcanary) 和 [GitHub Releases](https://github.com/Oscar-Williams/dsh-deepcanary/releases/tag/v0.1.6-rc.4)，`latest` 与 `next` 均指向此 RC。

本版加入后台任务持续跟踪和重载补收。健康任务保持安静，宿主无法确认的任务保留待确认状态。

选择稍后提醒的时间后，可在收件箱查看安排、改期或恢复待办。各次安排分别跟踪，到期后遵循当前通知策略；已安排的决定仍保留在收件箱中。

## 安装

### Desktop

从[发布资产](https://github.com/Oscar-Williams/dsh-deepcanary/releases/tag/v0.1.6-rc.4)下载 `dsh-deepcanary-0.1.6-rc.4.tgz` 和 `SHA256SUMS`。在 DSH 的“插件 → 添加插件”中通过官方管理器选择本地 tgz，按界面提示启用。需要重启时先保存进行中的工作。桌面版通过应用管理自己的 profile 与插件。

### WebUI

使用 DSH 0.2.1-rc.2，在明确的 Web profile 中安装：

```sh
dsh --version
dsh plugin --profile web add dsh-deepcanary@0.1.6-rc.4 --registry=https://registry.npmjs.org/
dsh web
```

通过 npm 运行宿主时，可以在每条命令前加 `npx --yes --package=@deepseek-ai/dsh@0.2.1-rc.2`。例如：

```sh
npx --yes --package=@deepseek-ai/dsh@0.2.1-rc.2 dsh web
```

打开 DSH 输出的认证地址。已构建的源码检出可使用其文档规定的 `pnpm dsh` 入口，并遵循该检出的包管理器版本。

使用已校验的 GitHub 压缩包安装时，填写本地文件路径：

```sh
dsh plugin --profile web add ./dsh-deepcanary-0.1.6-rc.4.tgz --registry=https://registry.npmjs.org/
```

### 更新与卸载

优先使用官方管理器提供的更新操作。当前管理器可能拒绝重复安装已存在的组合包；此时先在管理器中移除该包，再安装替换包。按实际生效或重启提示处理，并确认加载版本。

Web CLI 将包操作转交 pnpm。更新 Web 时，执行上方指定版本的安装命令，完成当前工作后停止对应 Web 宿主，重新执行 `dsh web` 并刷新页面，确认实际加载版本。卸载 Web profile 中的插件：

```sh
dsh plugin --profile web remove dsh-deepcanary
```

会话和配置由 DSH profile 管理。改变宿主进程前先保存当前工作。

## 使用

1. 从 DSH 侧栏打开 **DeepCanary**。
2. 在 DSH“设置 → 内置插件 → DeepCanary”中调整提醒级别、每小时打断预算和静默时段。
3. 按需启用浏览器通知，然后正常运行任务。
4. 从收件箱返回对应会话、查看依据、稍后处理或提供明确反馈。

| 级别 | 含义 | 行为 |
| --- | --- | --- |
| C1 | 已作决定 | 已作决定在收件箱等待复核，不打断你 |
| C2 | 需要决定 | 待处理决定遵循提醒级别、静默时段和滚动预算 |
| C3 | 需要及时处理 | 最高提醒级别，仅保留给宿主权威的阻塞条件 |

收件箱只包含决定。自动任务信号不会出现在收件箱、侧栏计数或通知中，即使达到 C2 或 C3。

每条决定携带独立 id，重复投递不会重复应用回答。决定在恢复和重载后保留，所属会话结束时条目仍然可见。

后台任务运行期间显示活动数量。结果会持续跟踪到完成并在重载后补收；宿主无法确认的任务保留待确认状态。

收件箱先列出待处理决定，再列出已作决定；更多决定可通过“显示更多”展开。每条决定按自己的提醒生命周期处理反馈和稍后提醒。

代理可以在不停止当前回合的情况下向你提出决定。它调用 `deepcanary_request_decision`，提供一句话的决定、说明、已考虑的替代方案、影响范围，以及最多五个可选项（每项不超过 120 个字符），然后继续工作。卡片标注为“待你决定”，显示可选项和所属会话，没有“已处理”操作，也不会过期；回答或由提出它的会话通过 `deepcanary_cancel_decision` 撤回后，它会离开“待处理”筛选，已回答条目仍保留在“全部”中。稍后提醒与改期同样适用于待处理决定。

已作出的决定也保留在同一收件箱，供后续复核。决定条目按根会话分组，子代理会话按委派深度嵌套；分组标题显示会话标题和工作目录。尚无会话标题时先显示工作目录的末级名称，标题事件到达后再更新。每个会话中的决定按时间顺序排列。“全部”是完整的默认视图；“待处理”“已作决定”“已复核”和“有异议”可缩小决定范围。“已作决定”筛选尚未复核的已作决定；“已复核”和“有异议”分别显示对应状态。相同筛选也适用于已安排的决定，它们仍按会话分组。自动任务信号不会进入收件箱；这里只列决定及其已安排的条目。

“稍后提醒”可选择5、15、30或60分钟，已安排的决定显示恢复时间，并支持查看、改期与恢复待办。到期后条目回到收件箱，待处理决定遵循静默时段和滚动预算。已回答或撤回的待处理决定离开“待处理”，已复核或提出异议的已作决定离开“已作决定”。本地 profile 保存决定历史、通知预算与发送状态，供插件重载后继续使用。实际送达取决于设备设置和应用生命周期。

面板使用不透明的深浅色表面，支持缩放、键盘及展开依据。返回操作通过 DSH 的公开会话目录确认目标。目标失效时保留摘要并说明当前可用性。

设置通过宿主配置服务持久化。并发修改产生冲突时保留草稿，放弃草稿后读取当前宿主值。插件替换会等待提醒状态写入结束，随后再读取新实例状态。

## 隐私

提醒状态保存在本地 profile，仅包含有界元数据、哈希引用、明确反馈和必要的本地会话导航句柄。会话原文、提示词、模型输出、工具参数和凭据由原有宿主服务管理。

HTTP 接口继承宿主认证及 Host/Origin 检查，限制 JSON 大小并使用脱敏错误。反馈按需提供，提醒是否有用由明确反馈表达。详见[安全说明](docs/security.md)和[反馈校准](docs/feedback-calibration.md)。

## 兼容性与限制

- 通知依赖持续运行的宿主和渲染页面、浏览器权限及操作系统设置；实际送达和点击结果需要设备观察。
- 桌面端共用核心、设置和收件箱；原生窗口唤回及渲染页面之外的通知需要宿主进一步提供公开能力。
- 设备验证面向 Windows WebUI 与 Desktop；CI 覆盖其列出的系统源码检查。
- Supervisor 为实验能力，默认关闭，其本地投影随所属宿主进程运行。
- 实时提醒采用确定性规则，真实反馈和独立评估用于改进后续策略。
